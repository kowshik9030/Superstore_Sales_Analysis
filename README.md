# Superstore Sales Analysis

Exploratory data analysis of the Superstore retail dataset in a Jupyter notebook: 30 numbered business questions answered with pandas, seaborn and matplotlib - yearly sales, profits and discounts, customer segments, region and category breakdowns, and top customers.

## Questions covered

- Total sales, profits and discounts per year
- Number of customers per segment; highest/lowest sales by segment and region
- Total sales and profits per year, segment, category and sub-category
- Relationship and correlation between sales and profits
- Category-wise sales, profits and discounts

## Tech stack

Python, pandas, NumPy, seaborn, matplotlib, Jupyter

## Usage

```bash
pip install pandas numpy seaborn matplotlib jupyter
jupyter notebook Superstore_Analysis.ipynb
```

The notebook expects the Superstore CSV (`Superstore.csv`) next to it and walks through data cleaning (date parsing, null checks, type conversion) before the analysis.
